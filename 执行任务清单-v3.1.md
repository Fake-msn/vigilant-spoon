## 0. 消费说明（执行工具先读）

1. **执行顺序**：Phase A（A0→A8）→ Phase F（F0→F5）。标注 `∥` 的线可并行（前端 FE / 后端 BE 互不阻塞）。
2. **模块门禁**：模块内全部指令完成后：
   ```
   自动检查（lint+typecheck / ruff+mypy）→ 测试（vitest / pytest）→ 人工审核 → 下一模块
   ```
3. **契约真源**：后端 `app/schemas/`（pydantic）为唯一真源；前端类型一律 `npm run gen:types` 生成，**禁止手抄**。契约字段细节不在本清单重复定义，引用核对清单章节号。
4. **五条铁律**（违反即打回）：
   - 门禁铁律：eslint/typecheck 不得配置任何 ignore；
   - WS 铁律：上行二进制 PCM16 帧（非 base64/JSON），下行 JSON 事件；
   - RAG 铁律：检索只出现在开场素材/备课/评语，对话轮次内无 RAG 工具；
   - 宠物铁律：三态转移纯函数零 LLM（daily/gray/cheer，见核对清单 §6-PetState）；
   - 演示铁律：演示只走确定性字段（理想/承诺/行动），不赌 RAG 召回。
5. **mock 开关**：前端 `VITE_USE_MOCK=true` 时 api/ws 全部路由到 `src/mocks/`；Phase A 全程 mock=true；Phase F 按就绪线逐批切 false。
6. **源码基线**：`web_src/`（Next.js Demo）只读，不改动；所有产出在新工程 `web-spa/`（前端）与 `server/`（后端）。
