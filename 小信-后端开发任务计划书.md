### 0.2 WebSocket 语音协议

```
WS /ws/voice?session_token={token}&mode={classroom|journal|lesson}
```

- **上行（前端 → 服务端）**：二进制帧，PCM16 @16kHz/16bit/mono，每帧 ≤80ms（约 2560 字节）。**不用 base64/JSON**。
- **下行（服务端 → 前端）**：JSON 事件（与 AgentScope `outgoing_queue` 官方路径兼容，音频字段 base64）。

| 下行事件              | 字段                              | 说明                 |
| ----------------- | ------------------------------- | ------------------ |
| `session_started` | `opening: string`               | 开场白文本（含档案注入），前端可显示 |
| `audio_chunk`     | `seq: number, data: base64`     | AI 语音音频块           |
| `transcript`      | `text: string, is_final: bool`  | 用户语音转写             |
| `turn_end`        | `final: bool`                   | 一轮结束               |
| `error`           | `code: string, message: string` | 错误事件               |

### 0.3 核心数据结构（pydantic 定义，`schemas/` 中唯一真源）

```python
# schemas/growth.py
class Commitment(BaseModel):
    id: str
    text: str
    created_at: datetime
    status: Literal["active", "fulfilled", "expired"]   # 确定性状态机，绝不 RAG

class PetState(BaseModel):
    species: str          # 职业方向决定外观族系
    stage: int            # 0..N 相邻迁移
    vitality: int         # 0..100，单次变化 ≤ ±15（服务端 clamp）
    growth_value: int
    mood: Literal["cheerful", "calm", "low"]
    updated_at: datetime

class GrowthView(BaseModel):
    ideal: str | None
    commitments: list[Commitment]
    last_gist: str | None          # 上次一句话摘要（确定性写入，非 RAG）
    growth_value: int
    stage: str
    pet: PetState
    # view=full 追加：actions/history/scores（L2 结算视图）

class ScoreCard(BaseModel):        # 结算链产物，可申诉
    session_id: str
    student_id: str
    dimensions: dict[str, int]     # rubric 各维度分
    total: int
    evidence: list[EvidenceItem]   # 证据链：命中 rubric + 原文 span + 画像字段
    created_at: datetime

class EvidenceItem(BaseModel):
    rubric_id: str
    quote_span: tuple[int, int]    # 带时间戳的原文 span，非 LLM 复述
    source: Literal["transcript", "profile"]
    note: str
```

（其余：`ClassInfo` / `EnterReq` / `EnterResp` / `JobRef` / `JobStatus` / `Letter` / `LessonGenReq` / `LessonPlan` / `ControlReq` / `ClassroomStatus` 与前端 §0.3 语义一一对应，字段以后端 `schemas/` 为准。）

## 1. 后端架构与模块划分

```
app/
├── main.py           # FastAPI 入口，挂载 routers
├── schemas/          # pydantic 契约（唯一真源，导出 OpenAPI）
├── routers/          # 按域拆分：classes / session / growth / letters / lesson / classroom
├── services/         # ai 能力注册表（工具函数挂载点）
│   ├── voice.py      # RealtimeAgent 工厂（三角色模式）
│   ├── scoring.py    # 评分（吃全文 + ScoreCard evidence）
│   ├── pet.py        # 宠物状态机纯函数 + 约束断言
│   ├── rag.py        # 外围（仅开场素材/备课/评语检索） RAG
│   └── letter.py     # 写信 job（首版模板）
├── jobs/             # APScheduler 注册 + tenacity 重试装饰器
├── db/               # SQLite + 迁移（growth 结构化主表）
└── ws/               # 二进制上行适配层（bytes → ClientEvents）
```

**可扩展性设计（要求 4）**：

- `services/` 统一为**工具函数注册表**（AgentScope Toolkit 挂载点）→ 新增能力=新增一个函数+注册，不侵入 RealtimeAgent。
- 三角色（classroom/journal/lesson）通过 `RoleConfig` 注册表扩展：`{"mode": RoleConfig(sys_prompt, toolkit, injection_fields)}` → 加角色=加一条配置。
- 结算链设计为**可插拔 step 管线**（`settle_pipeline: list[Step]`，每步 `(name, fn, retryable)`）→ 加环节=插入一个 Step，测试按 step 断言。
- growth 表预留迁移版本（`db/migrations/`），二期加字段只走迁移，不动既有代码。

## 3. 门禁流程与协作规则

1. **模块状态机**：⬜ 未开始 → 🔨 实现中 → ✅ 自动检查通过 → 🧪 测试通过 → 🙋 待人工审核 → 🏁 审核通过。测试失败打回 🔨。
2. **审核请求**：🧪 通过后提交「模块名 + pytest 输出 + 变更文件列表」，由非本模块负责人复核审核要点。
3. **并行规则**：B1（spike）与 B0 并行首日完成；B2/B3 可并行 B4 前的准备；B4 依赖 B3 转写通路。与前端并行就绪时间表见下。
4. **接口就绪时间表**（前端可据此排 M 模块联调）：
   | 后端模块完成 | 前端可联调 |
   | ------ | ----- |
   | B2     | M1    |
   | B3     | M2/M3 |
   | B4     | M4    |
   | B5     | M6    |
   | B6     | M5    |
5. **契约变更**：改 `schemas/` → 双端同步第 0 章 + 通知前端 `npm run gen:types` + 双方跑对应模块测试。
