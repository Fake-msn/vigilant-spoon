## 1. 逐接口请求/响应字段核对（R1-R17 + WS）

> 每接口核对三列：请求字段完整性 → 响应字段完整性 → 关键语义。
> 验证方法统一为：curl/pytest（后端）+ vitest mock（前端）+ 联调矩阵（§迁移清单 9.5）。

### R1 `GET /api/classes/{class_code}` → ClassInfo

| 核对点 | 期望 | 验证 |
|--------|------|------|
| 响应字段 | `class_code, class_name, school, region_key, grade, class_no, students: StudentProfile[]` | `curl localhost:8000/api/classes/CLS001 \| jq` |
| StudentProfile 字段 | `student_id, name, student_no, avatar_seed, role`（A2） | jq 断言五字段齐全 |

## 2. HTTP 状态码 / 错误码 / 错误体（A9）

**统一错误 envelope**（所有 4xx/5xx 必须遵守）：

```json
{ "code": "STUDENT_NOT_FOUND", "message": "该班级名单中没有这个名字", "details": { "candidates": ["王小雅", "吴小雪"] } }
```

| HTTP | code | 触发场景 | 前端行为 |
|------|------|----------|----------|
| 400 | `BAD_REQUEST` | 路径/参数格式错 | toast 提示 |
| 401 | `TOKEN_INVALID` / `TOKEN_EXPIRED` | token 缺失/伪造/过期 | **清 sessionStorage，重定向 `/`** |
| 404 | `CLASS_NOT_FOUND` / `STUDENT_NOT_FOUND` / `JOB_NOT_FOUND` | 见各接口 | 对应错误态 UI |
| 409 | `STATE_CONFLICT` | 课堂非法迁移 / job 状态冲突 | 刷新状态后重试 |
| 422 | `VALIDATION_ERROR` | 字段校验失败（FastAPI 默认 422 需包一层转为 envelope） | 表单字段级提示 |
| 429 | `RATE_LIMITED` | 生图/写信触发过频 | 退避重试 |
| 500 | `INTERNAL` | 未捕获异常 | 通用错误页 + 上报日志 |

核对点：① 抽查每个接口至少 1 条异常路径，响应体**必须匹配 envelope**（FastAPI 的 RequestValidationError 默认格式不合规，需全局 exception handler 包裹）；② `message` 面向用户可读（中文），`code` 面向程序；③ 5xx 不泄漏堆栈/SQL。

## 3. 分页 / 过滤 / 排序 / 幂等通用约定

| 约定 | 规则 | 核对点 |
|------|------|--------|
| 分页 | cursor 制：`?cursor=&limit=`（默认 20，最大 50）；响应带 `next_cursor: string\|null`。**仅 R7 信件分页**；R15/R16/R17 单班全量（≤60 人/课）不分页 | R7 造 25 条翻页：不重不漏、next_cursor 终止为 null |
| 排序 | R7 按 generated_at 倒序；R16 按 date 倒序；R17 gray 优先再按 growth_value 倒序；排序规则写进契约注释 | 逐接口顺序断言 |
| 过滤 | 演示期仅 R15 支持 `?subject=` 过滤（可选）；其余不过滤，不预留参数 | — |
| 幂等 | R2 重放签新 token；R5/R8 用 `Idempotency-Key` header（同 key 返回同 job）；R12 用 `client_cmd_id` 去重；R14 按 student_no upsert；结算链按 session_id 唯一约束（B4 已有） | 五类幂等各有重放用例 |
| 时间格式 | 全部 ISO 8601 带时区（`2026-08-06T16:00:00+08:00`）；前端不做时区换算假设 | 抽查响应体时间字段可被 `Date.parse` 解析 |

## 4. session_token 机制（A8，v2.0 全文未定义，本节为补齐契约）

| 项 | 契约值 | 核对点 |
|----|--------|--------|
| 格式 | `st_` 前缀 + 32 字节 urlsafe（如 `st_9f3k...`）， opaque token，**非 JWT**（无自包含声明，服务端查表） | 正则要 `^st_[A-Za-z0-9_-]{40,}$` |
| 签发 | 仅 R2；绑定 `student_id + class_code + issued_at + expires_at` | 库表字段断言 |
| 有效期 | 固定 **12 小时**（覆盖单场演示+彩排），不做滑动续期 | 伪造过期 token → 401 `TOKEN_EXPIRED` |
| 刷新 | **无刷新机制**：过期即回 `/identity` 重新点选（演示边界，重进成本极低） | 前端 401 流程走查 |
| 撤销 | 不主动撤销；重复进入签新 token，旧 token 继续有效（B2 审核要点②）；演示结束清库即全失效 | pytest 用例④复跑 |
| REST 传递 | `Authorization: Bearer st_...` header | 抽查受保护接口无 token → 401 |
| WS 传递 | query 参数 `?session_token=`（WS 握手无 header 自定义能力）；服务端握手时校验，失败即 close code `4401` | wscat 无 token 连接断言被拒 |
| 存储 | 仅 sessionStorage（关标签即清）；**禁止** localStorage / cookie | 前端代码评审 + M1 审核要点② |
| 保护范围 | R3-R17 + WS 全部需要 token；R1 名单接口可匿名（进入前就要用）；R2 匿名 | 逐接口无 token 请求断言 |

## 5. WebSocket 全量事件定义（A7 补全后）

`WS /ws/voice?session_token={token}&mode={classroom|journal|lesson}`

### 上行（前端 → 服务端）

| 帧类型 | 格式 | 说明 | 核对点 |
|--------|------|------|--------|
| 音频帧 | **二进制**，PCM16 @16kHz/16bit/mono，≤80ms/帧（≤2560B） | 不用 base64/JSON | 抓包确认 opcode=Binary；帧字节数断言 |
| 协议心跳 | WS 协议层 ping/pong（非业务帧） | 服务端 30s 无 pong 主动断开 | 断网模拟重连用例 |
| 控制帧 | **演示期不开放**（不发打断/取消；不抢话铁律由前端互斥状态保证） | 上行只有音频 | 代码评审确认无其他上行类型 |

### 下行（服务端 → 前端，JSON 文本帧）

| 事件 | 字段 | 时序位置 | 核对点 |
|------|------|----------|--------|
| `session_started` | `{opening: string}` | 握手成功后首个事件 | 开场白含注入的理想/承诺（断言关键字段 100%） |
| `vad_start` | `{}` | 判定学生开始说话 | 与录音起点对齐（误差 <200ms） |
| `vad_end` | `{}` | 判定学生停止说话 | **首响探针起算点 B**（A7 补齐项，缺它 M6 无法验收） |
| `audio_chunk` | `{seq: number, data: base64}` | AI 语音流，seq 单调递增 | 乱序到达按 seq 重排播放（FE-M3 用例②） |
| `transcript` | `{text, is_final: bool}` | 学生转写流 | is_final=true 后不再变更 |
| `turn_end` | `{final: bool}` | 一轮结束 | 之后前端恢复可录音 |
| `session_end` | `{reason: normal\|timeout\|error}` | 服务端主动收尾 | 前端落盘结算触发点 |
| `error` | `{code, message}` | 任意时刻 | UI 提示不崩溃（FE-M3 用例④） |

**时序核对（单轮）**：`vad_start → vad_end → audio_chunk*(seq 连续) → transcript(is_final) → turn_end`。
**重连语义**：token 有效期内可重连；重连后重发 `session_started`（opening 重发可接受），**不重放**历史 audio_chunk；seq 在新连接内重新从 0 开始。
**关闭码**：`4401` token 无效/过期；`4409` mode 非法；`1011` 服务端内部错误。

## 7. 文件上传 / 对象存储 / 图片 URL 契约

| 场景 | 契约 | 核对点 |
|------|------|--------|
| 学情文件导入（R14） | `multipart/form-data`，字段名 `file`，限 .xlsx/.csv、≤2MB；超限/格式错 → 422 + `details.reason`；解析失败行在 `details.failed_rows[]` 返回 | 上传 3MB 文件断言 422；含坏行文件断言 failed_rows |
| 生图产物（R6 result_url） | 演示期**本地磁盘 + 静态挂载**：相对路径 `/static/portraits/{job_id}.png`，前端拼 baseURL；不二进制内嵌、不外链 | GET result_url → 200 + Content-Type: image/png |
| 教师大头照 / 课堂配图 | **P2 可选，演示期用内置 TeacherAvatar**；若做：`POST /api/classes/{code}/avatar`（multipart，≤2MB，png/jpg）→ `{url}` 入 ClassInfo | 不做则在计划书标注"演示期省略"，避免联调期临时起意 |
| 学生照片 | 不接真实照片，`avatar_seed` 驱动 KidAvatar 程序化生成（隐私红线：不入库儿童照片） | 审核确认无照片上传入口 |
| 对象存储 | 演示期不上 OSS；接口层面 URL 一律相对路径，未来切 OSS 只改服务端静态层，契约不变 | 契约评审确认无绝对 URL 假设 |
