# 小信 · 演示谈心脚本

> 来源：`web/lib/data.ts` 中的 `chatScript`  
> 用途：演示脚本底稿，供教师线/学生线彩排参考。确定性字段（理想/承诺/行动）由后端 seed 持有，前端不直接持有业务话术。

## 角色

- **小信**：AI 谈心伙伴
- **王小雅**：三年级学生，理想是成为蛋糕师

## 对话流程

1. **小信**：你好呀！我是小信 ✨ 今天想和你聊聊你的梦想。你长大以后想做什么呀？
2. **王小雅**：小信，我长大了想卖蛋糕！我最喜欢吃甜甜的蛋糕了
3. **小信**：长大以后想卖甜甜的蛋糕也太美好啦～那你最喜欢什么口味的蛋糕呀？你有没有试着做过蛋糕呢？哪怕帮妈妈打打下手也算哦～
4. **王小雅**：有！我上周帮妈妈揉了面团，虽然弄得满脸都是面粉……
5. **小信**：哈哈哈太可爱了！满脸面粉也是蛋糕师的勋章呢 👏 你看，我已经能想象出你当蛋糕师的样子了——
6. **小信**：[图片：梦想小蛋糕] 先送你一个梦想小蛋糕！再聊两句，我就把你的专属电子宠物画出来～
7. **王小雅**：好呀！我还想学会做草莓味的纸杯蛋糕，带给班里的同学吃
8. **小信**：[图片：专属电子宠物] 叮咚——你的专属电子宠物生成啦！戴着厨师帽、拿着打蛋器的小蛋糕师，以后它会陪着你一起长大。记得我们的约定：这周再帮妈妈做一次小点心哦！

## 关键确定性字段

- **理想（ideal）**：蛋糕师
- **本周小行动**：再帮妈妈做一次小点心
- **心理信号**：无（状态为日常/开心）
